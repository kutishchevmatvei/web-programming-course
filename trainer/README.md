# Проект trainer

`trainer/` — единая рабочая папка приложения курса. Проект начат на L1: в `src/domain.ts` находятся типы и функции предметной области A1, а `src/demo.ts` сохраняет демонстрацию этих функций. На L2 к той же версии добавлены React и Vite, каталог заданий и экран выбранного задания.

Точные версии зависимостей и конфигурация соответствуют [материалам L2](../lessons/l2/README.md). Проверяйте приложение из этой папки:

```sh
npm run check
npm run build
npm run demo
npm run dev
```

Это часть маршрута обучения:

1. На L0 вы сохраняете результат стартовой практики HTML/CSS/JavaScript — портфолио фотографа — в `lessons/l0/`.
2. На L1 создаёте TypeScript-модель и функции A1 в `trainer/`.
3. На L2 продолжаете этот проект, подключаете React и Vite и добавляете отображение набора заданий.
4. На L3 добавляете локальную попытку с формами и обзором ответов, а на L4–L5 расширяете её черновиком и HTTP.
5. На L6 подключаете Vitest и React Testing Library для проверки поведения.

Материалы этапов описывают инфраструктуру и не заменяют вашу реализацию заданий.

## Учебный сервер

Сервер запускается из корня репозитория, а не из `trainer/`. Команда одинакова в Linux и Windows PowerShell:

```sh
node course/server/server.mjs
```

Он доступен на `http://localhost:3001`; формат маршрутов описан в [контракте](../course/CONTRACT.md). Сервер и [учебный JSON](../course/data/training-set.json) уже входят в репозиторий и не требуют переноса в `trainer/`.

## Порядок работы

После каждого этапа оставляйте проект в `trainer/`, фиксируйте рабочую точку коммитом и создавайте следующую ветку от версии, которая уже содержит предыдущий этап. Сверяйте команды с README текущего этапа: до L6 `npm test` не требуется, а тестовый скрипт и зависимости настраиваются на L6.
